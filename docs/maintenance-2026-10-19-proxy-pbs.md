# 0.3.3：代理与旧版 PBS 兼容修复

以下为匿名化的实机验收结论。账户、服务器与代理地址、工作区名称、作业编号、文件校验值及原始日志路径仅保留在本机私有记录中。

## 已确认并修复

- 旧注册端口可能覆盖 SSH config 中的非默认端口，导致快速拒绝；延长等待不能修复错误端口。修复注册前应确认端点并备份原记录。
- Windows 父环境 SHELL 为 PowerShell 时，配套 Cygwin OpenSSH 的 ProxyCommand 前缀 exec 不兼容。POSIX shell 选择仅作用于 rsync 子进程，不修改全局 shell、密钥或代理配置。
- Torque 4.2.7 可能保留 #PBS 日志路径的引号。现在通过 qsub -o/-e 传递真实参数，简单路径指令不带引号；Torque 在日志目录使用 scheduler 前缀。
- Torque 数组模板可能保持 R，但具体子任务已 C/失败。查询具体元素并聚合，避免模板掩盖终态。
- PBS 只有一个命令组时，两种方言均使用普通作业并固定 TASK_ID=1，保留同一命令分组、日志和状态格式。

## 尚未通过的边界

三个小型数组验收均已核对子任务终态和日志。首个因日志路径启动失败，随后暴露站点启动器的 zsh 方括号解析错误；改变提交进程 SHELL 未解决，未保留为产品行为。不能宣称该站点多元素数组已通过。可先将步骤写入单个脚本，经 PBS 普通作业路径执行；数组启动器仍需站点侧处理。未修改用户远端登录 shell、启动文件或集群服务。

本次使用独立的新 MCP 进程验收，不能把运行中的旧进程视作自动升级。服务器与客户端时钟有差异，完成依据为调度器终态、退出码、完成标记、文件内容和校验，而非 mtime。
